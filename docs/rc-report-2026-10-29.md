The constructor takes one argument: `address usdcAddress`.

- This value is public and well-documented; it is not a secret

### Fail-closed guarantee

`src/contracts/sessionSplit.ts` line 12–18:

```typescript
if (IS_MAINNET && !MAINNET_ADDRESS) {
  throw new Error(
    "[SeshPay] VITE_NETWORK=mainnet is set but the mainnet contract address " +
    "has not been recorded..."
  );
}
```

This executes at module load time in the browser. A mainnet build with an empty `MAINNET_ADDRESS` **will crash immediately on every page load** — it cannot silently fall back to the testnet contract. `vite build` itself succeeds, but the deployed app will be completely non-functional until the address is set.

### Truthful project description (draft)

> **SeshPay** is a USDC payout coordinator built on Arc, Circle's blockchain where USDC is the native gas token. It allows event sponsors to deposit USDC and atomically pay a host and up to five contributors in a single on-chain transaction. Sponsors retain full custody until settlement — there is no platform fee, no admin key, and no upgradeability.
>
